## Featured Projects

### Secure Homelab

Production-inspired infrastructure architecture emphasizing segmentation, least privilege, identity, PKI, secure remote access, logging, and documented trust boundaries.

### DNS / NTP Infrastructure

Dedicated DNS and time appliances designed around separate trust domains, controlled exposure, hardened Linux systems, and validation-first rollout.

### Administrative Laptop Hardening

A dedicated administrative Linux workstation designed for privileged infrastructure access with encryption, Secure Boot, auditing, and attack-surface reduction.
